# Veritas Legal — Law Firm Website

A modern, responsive law firm website built with **React.js** and **CSS**. This project was developed as a real-world frontend freelancing project, focusing on responsive UI, reusable React components, smooth navigation, and an interactive user experience.

## 📌 About the Project

This project is a frontend website designed for a law firm/business-style website.

The goal was to create a professional website with:

* Clean and modern UI
* Responsive design across desktop, tablet, and mobile
* Smooth navigation between different sections
* Interactive buttons and components
* Contact and consultation functionality
* Reusable React components

The project also gave me practical experience working on a real client-oriented frontend project and understanding how development requirements can change during the process.

## 🧩 React Components

The website is divided into reusable components instead of keeping the entire website inside one file.

Some of the main components include:

* **NavBar** — Website navigation and contact/consultation actions
* **Home** — Main landing section
* **About** — Company/about section
* **Service** — Services section
* **CaseStudy** — Case study/content section
* **ClientTest** — Client/testimonial section
* **PopUp** — Reusable consultation popup

This component-based structure made it easier to develop and maintain individual sections independently.

---

## 📱 Responsive Design

The website was designed to work across different screen sizes:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet
* 🖥️ Larger screens

Responsive CSS media queries were used to adjust layouts, spacing, typography, cards, navigation, and popup components for smaller screens.

## 🚀 Running the Project Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd YOUR_PROJECT_NAME
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will then be available on the local development server provided by Vite.
